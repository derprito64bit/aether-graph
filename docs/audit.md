## What is genuinely excellent (keep, with attribution)

1. **Re-clocked Catmull-Rom sampler** (`src/film/camera.ts`). Three's `CatmullRomCurve3` uses uniform knots, so raw progress lands key `i` at `i/(N-1)` instead of authored `at`. The reference maps progress onto the authored segment clock before sampling, keeping camera travel, pose, and FOV on one timeline. Keep the reasoning and add a unit test asserting each authored key lands at its authored progress within epsilon.
2. **Separate film material set.** `PhoneModel` accepts an optional per-instance material set; the film builds its own so the x-ray opacity dissolve never leaks into product-page viewers. Keep this design.
3. **Fit-based responsive framing** (`src/film/framing.ts`). Hero keys carry a `fit` share-of-viewport-height target converted to vertical FOV with a horizontal-silhouette guard, monotone aspect-tier policy (`formatFit`), `centerBias`, and a narrow-viewport macro floor. Keep and add projection tests over aspect 0.5 to 3.6.
4. **HTML OS overlay crossfade** at the software act instead of a pixel-perfect screen projection. Far more robust. Keep.
5. **Deterministic pure battery math** (`src/utils/battery.ts`). Keep and unit test.
6. **Local-only procedural assets.** SVG finishes and camera scenes, `Lightformer` panels plus procedural canvas env sphere, no remote HDR. Keep. Hard constraint: zero third-party runtime requests.
7. **Performance skeleton.** `three` split into its own chunk, film scene dynamic chunk, `IntersectionObserver` canvas mounting, DPR caps (1.75 desktop / 1.3 mobile), live screen redraw at ~9 fps, rail viewers skipped below `lg`. Keep and upgrade to adaptive quality (section 8.3).
8. **CSS `PhoneFrame` front and rear fallback** for WebGL failure. Keep and extend to all rear-facing acts.
9. **Engineering hygiene that is already right.** Strict TS flags (`verbatimModuleSyntax`, `erasableSyntaxOnly`), Tailwind v4 `@theme` tokens, Motion `useScroll` with no `window.addEventListener('scroll')`, damped rotation (~5.5/s), one-line doc comments with units. Match or beat.

## What to restructure (v2 requirements)

- **Timeline authoring is unreadable.** `story.ts` authors ~35 keys through a 16-arg positional helper `KS(at, rx, ry, ...)`. Works but unvalidatable. Replace with object-literal keyframes authored per act in `src/film/acts/<act>.ts`, a typed `key({ at, pose, camera, lens, look })` API, and a validator (strictly increasing `at`, first 0 / last 1, every act boundary covered both sides, no NaN, `fit` in (0,1.4], `fov` clamps, camera outside phone bounding volume). Add dev scrubber overlay (`.` toggle, slider, act readout, copy-pose-as-keyframe, `?t=` deep link) driving the visual-regression captures.
- **Files over ~300 lines must split.** Largest offenders: `film/scene/internals/parts.tsx` (28 KB), `film/scene/internals/materials.ts` (25 KB), `PhoneModel.tsx` (589 lines), `FilmDirector.tsx` (429 lines), `film/overlay/primitives.tsx` (541 lines). Plan: internals becomes a material registry plus per-subsystem modules (board, silicon, power, optics, chassis) each with factory and disposal; phone model splits into geometry construction, material binding, component shell; overlay becomes one primitive per file. Enforce a `src/lib/` boundary (no React, no three) via lint.
- **Color management is implicit.** Make explicit: enable `THREE.ColorManagement`, pick one tone-mapping curve (AgX or ACES Filmic), per-act exposure in the lighting state, author colors in sRGB once. Document in `docs/rendering.md`.
- **Glass is Tier 3 only.** Current `.glass` is blur plus saturate. Ship one `<Glass>` primitive with three tiers: (1) WebGL transmission on hero surfaces, (2) SVG displacement refraction (Chromium `backdrop-filter: url(#…)`), (3) layered fallback. Capability detection at mount, tier on a data attribute, tokens only, reduced-transparency and forced-colors collapses, `docs/glass.md` with three-tier screenshots.
- **Zoom is only camera dolly.** Add named modules: Vertigo dolly-zoom once at chip entry, infinite-zoom match cut (phone to die, die to sensor), pinned 2D zoom sections, low-amplitude reveal zoom, decorative-only CSS `animation-timeline`. Rules: never hijack scroll, damp driving values, transform and opacity only, `will-change` toggled in-range, CLS zero, layer ceiling documented.
- **No tests, CI, formatter, license, or boundaries.** Add: vitest unit (battery, framing, sampler, act lookup, glass displacement, zoom math, formatting), timeline invariants (monotonic, coverage, continuity over 1000 samples, authored-key landing, FOV clamps), spec-consistency (overlay numbers exist in `src/data/`), no-network scan, Playwright e2e (routes, skip link, configurator material change, OS open/close, Hz slider, zoom scrub), visual regression (`?t=` × ~20 progress × 5 viewports, frozen time, DPR 1), axe on every route in both motion modes. CI: job 1 typecheck/lint/format/unit, job 2 build/budget/e2e, job 3 nightly Lighthouse. `prettier`, `LICENSE` (MIT) plus fiction disclaimer in README, footer, specifications page. Per-route error boundaries plus a 3D-stage boundary, `webglcontextlost` handling to the CSS phone.
- **Fixed caps instead of adaptive quality.** Start ~1.75 DPR desktop / 1.3 mobile, then scale DPR, transmission resolution, glass tier, and postprocessing from measured frame time. Postprocessing (`postprocessing` / `@react-three/postprocessing`) only with an ADR and measurement. Enforce budgets in `scripts/bundle-budget.mjs`: initial JS excl. three under 180 KB gzip, three own chunk lazy, film scene dynamic, CSS under 40 KB gzip, geometry plus textures under 1.5 MB compressed, first paint of `/` under 400 KB gzip. LCP under 2.0 s, CLS under 0.05, INP under 200 ms under 4x throttle plus Fast 3G; 55 fps+ sustained.
- **Reduced motion is a kill switch, not a layout.** Ship a real static story layout (each act a composed still beside copy), snap poses, opacity-only chapters, crossfade zooms, visible Skip-the-film control moving focus, `aria-live` act announcements, keyboard film navigation, per-act canvas descriptions, `prefers-reduced-transparency`, `prefers-contrast`, `forced-colors`, `<noscript>` core info.
- **Missing authoring docs.** Add `docs/FILM.md` (new act in an afternoon), `docs/glass.md`, `docs/motion.md` (shot grammar, zoom modules, tokens), `docs/rendering.md`, `docs/design-tokens.md` (contrast numbers), `docs/adr/` (re-clocked curve, separate material set, fit FOV, HTML OS overlay, Motion over GSAP, WebGL glass on heroes), README architecture diagram (inline SVG), `docs/perf.md` trace numbers, dev-only `/dev/kitchen-sink` excluded from prod bundle.
- **Animation runtime decision.** Single runtime only. Default: Motion (reference choice, MotionValue-driven film). GSAP MCP (`@vinhnguyen/gsap-mcp`) stays installed but unused unless an ADR justifies a switch. Do not ship both.
